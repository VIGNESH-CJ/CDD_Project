# Figma Import and Prototype Guide

The repository includes a print-ready SVG wireframe and the complete UI blueprint.

1. Open Figma and create a team/file named `AI Foodie`.
2. Import `docs/figma-ai-foodie-wireframe.svg` as a frame reference.
3. Create 390 x 844 customer frames and 1440 x 1024 admin, kitchen, and delivery frames.
4. Apply the design tokens and component states from `docs/FIGMA_UI_UX_SPEC.md`.
5. Link the customer, admin, kitchen, and delivery journeys described in the specification.
6. Add prototype states for successful checkout, cancelled payment, allergy conflict, GPS denied, and delayed delivery.
7. Export the interactive prototype link and key desktop/mobile screenshots into the project report.

This guide is repository-based handoff material. Creating a hosted Figma file requires an account and manual sharing by the project team.
